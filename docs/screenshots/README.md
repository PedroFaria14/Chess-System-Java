# Screenshots

`desktop.png` e `mobile.png` são capturas da aplicação real durante os testes Playwright, com uma partida local de demonstração.

`desktop-stockfish.png` e `mobile-stockfish.png` mostram uma partida contra o motor real, no nível fácil.

Para atualizar as capturas de documentação, execute a suíte com `UPDATE_SCREENSHOTS=1`. Os testes normais gravam suas evidências apenas em `frontend/test-results/`.
